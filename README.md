# Fisheye Undistort GUI

피쉬아이 카메라 영상의 왜곡을 보정하고, 보정된 이미지 위에 주차면을 편집할 수 있는 브라우저 기반 도구입니다.

## 주요 기능

### 언디스토션
- 피쉬아이 카메라의 K, D, P 행렬 및 회전 파라미터를 조정하여 실시간 왜곡 보정
- 원본 이미지와 보정된 이미지를 나란히 비교
- 원본 이미지에 언디스토션 경계선(초록색) 오버레이 표시
- 파라미터 JSON 불러오기 / 저장
- 보정된 이미지 저장

### 주차면 편집
- 보정된 이미지 위에 최대 8개의 주차면 영역 설정
- 4개의 꼭짓점을 드래그하여 사각형 모양 자유 조정
- 각 주차면 ID 설정
- 꼭짓점 픽셀 좌표를 JSON으로 저장

## 시작하기

### 요구사항

- Node.js 18 이상

### 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

### 빌드

```bash
npm run build
```

## 사용 방법

### 언디스토션

1. 좌측 사이드바에서 🔧 **언디스토션** 선택
2. **이미지 선택** 버튼으로 JPG/PNG 파일 로드
3. K Matrix, D Coefficients, P Matrix, Rotation 파라미터 조정
4. 왼쪽 패널에서 경계선 위치, 오른쪽 패널에서 보정 결과 확인
5. **파라미터 저장** / **이미지 저장** 버튼으로 결과 출력

### 주차면 편집

1. 좌측 사이드바에서 🅿 **주차면** 선택
2. 이미지 파일 선택
3. 주차면 수 입력 (1 ~ 8개) 후 **생성** 클릭
4. 각 사각형의 꼭짓점을 드래그하여 위치 조정
5. 하단 패널에서 각 주차면 ID 입력
6. **JSON 저장** 클릭

### JSON 출력 형식

```json
[
  {
    "id": "P1",
    "points": [[120, 430], [380, 430], [380, 820], [120, 820]]
  },
  {
    "id": "P2",
    "points": [[380, 430], [640, 430], [640, 820], [380, 820]]
  }
]
```

`points` 배열의 순서는 좌상 → 우상 → 우하 → 좌하입니다.
